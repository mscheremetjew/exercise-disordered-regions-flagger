# Requirements

This directory stores approved product requirements for the project.

**Primary skill:** `c-manage-product-requirements`

## Contents

- `product_requirements.md`: authoritative requirements baseline for the initial release and later approved increments.

## Scope Rules

Keep this stage focused on product behavior, user stories, and acceptance criteria.

Do not place architecture design, implementation plans, or release/deployment procedures in this directory.

Do not create separate repository issues for acceptance criteria. Acceptance criteria remain inside user stories in `product_requirements.md`.

Do not skip required approval gates.
