# Implementation

This directory tracks implementation planning and execution status for approved work.

**Primary skill:** `g-implement-repository-work`

## Contents

- `backlog_priority.md`: manual priority guidance for unresolved approved work items.

## Scope Rules

Use this directory for implementation coordination and prioritization.

Do not store product requirements here.

Do not store architecture baseline documents here. Code-level architecture stays under `sdlc_docs/02_architecture/code-level.md` and `sdlc_docs/02_architecture/containers/<container>/code-level.md`.

Do not create BDD validation scenarios here. Validation assets belong under `tests/validation/`.

Do not skip required approval gates.
